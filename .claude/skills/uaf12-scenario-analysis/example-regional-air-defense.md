# 范例:区域防空场景(精简版)

用于对照写法与粒度,新场景不要照抄内容,只借鉴结构。

目录:1 输入 · 2 能力 · 3 作战 · 4 服务与资源 · 5 需求 · 6 效能估算 · 7 本案例的修订教训

## 1 输入

己方:相控阵雷达 3(半径 300 km)、ESM 2(半径 400 km)、指挥所 1(含 AI 指挥系统、态势系统)、地空导弹系统 2(打击 30~260 km);各探测设备配边缘信息处理装备。敌方:固定翼作战飞机 1 架。部署区域:500 km × 500 km(用户确认后)。

流程 8 步:发现 → 融合初判与上报 → 识别与意图判断 → AI 方案与决策 → 任务下达、发射与引导 → 持续跟踪 → 击毁 → 毁伤评估与态势显示。

## 2 能力

| 编号 | 能力               | 实现主体              |
| ---- | ------------------ | --------------------- |
| C1   | 空情探测           | 雷达                  |
| C2   | 电磁侦察           | ESM                   |
| C3   | 信息融合           | 边缘处理、指挥所      |
| C4   | 目标识别与意图判断 | 边缘处理、AI 指挥系统 |
| C5   | 指挥决策           | AI 指挥系统、指挥员   |
| C6   | 火力打击           | 地空导弹系统          |
| C7   | 毁伤评估           | 雷达、ESM、指挥所     |
| C8   | 态势呈现           | 指挥所态势系统        |

依赖:C1、C2 → C3 → C4 → C5 → C6 → C7 → C8,C8 反馈支撑 C5。

## 3 作战

作战活动 12 项:OA1 空域搜索、OA2 电磁侦察、OA3 多源信息交换与融合、OA4 跟踪监视并上报、OA5 目标识别与意图判断、OA6 威胁评估与方案生成、OA7 方案决策、OA8 打击任务下达、OA9 发射与制导、OA10 拦截与击毁、OA11 毁伤评估与上报、OA12 全流程态势显示。

步骤对应:1→OA1、OA2;2→OA3、OA4;3→OA5;4→OA6、OA7;5→OA8、OA9;6→OA4(并行);7→OA10;8→OA11、OA12。

信息交换 8 条:IE1 敌机→探测设备(物理交互)、IE2 探测设备↔边缘处理、IE3 边缘处理→指挥所、IE4 指挥所→指挥员、IE5 指挥员→指挥所、IE6 指挥所→导弹单元(打击任务)、IE7 指挥所/边缘处理→导弹单元(引导数据)、IE8 探测设备→指挥所(毁伤评估)。

建模要点:泳道按执行者;OA4 与 OA8~OA10 并行;OA5 设识别置信度判断;OA11 判断是否毁伤,未毁伤回到 OA6(补充分支,报告里说明)。

## 4 服务与资源

服务 7 项:空情探测、电磁侦察、融合航迹、决策支持、火力打击、毁伤评估、态势显示。

资源:雷达 3、ESM 2、边缘处理装备 5(假设)、指挥所 1、导弹系统 2。实例:Radar-1~3、ESM-1~2、MSL-1~2、CP-1。

## 6 效能估算(示例假设)

- 预警缓冲 = 雷达 300 km − 导弹远界 260 km = 40 km(雷达与导弹同址或相近、直线接近)。
- 敌机 300 m/s:约 133 s;600 m/s:约 67 s。该时间要覆盖融合、识别、方案、决策、下达。
- 区域 500 km × 500 km 时设备间距可达数百公里,缓冲随雷达与导弹距离增大而减小,需依靠其他雷达或 ESM 前出探测提供目标指示。
- 侧向穿越要结合航路捷径与近界 30 km 另行分析。
